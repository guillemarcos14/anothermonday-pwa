CONTEXTO DEL PROYECTO

Desarrollo de una Progressive Web App (PWA) completa para "monno", una cafetería de especialidad. El objetivo es digitalizar la experiencia del cliente para aumentar la eficiencia operativa y la facturación. La aplicación debe ser completamente funcional, moderna, minimalista con toque futurista, y lista para ser desplegada como TFG (Trabajo Final de Grado).

ARQUITECTURA TÉCNICA

Stack Tecnológico Recomendado:





Frontend: React + Vite (o Next.js)



Estilo: Tailwind CSS + Framer Motion (animaciones)



Estado: Context API o Zustand



PWA: Workbox para service workers



Backend simulado: JSON Server o Firebase (Firestore + Authentication)



Pagos: Stripe (modo test) o simulación visual



Notificaciones: Firebase Cloud Messaging o simulación

NOTAS IMPORTANTES





Priorizar funcionalidad sobre complejidad visual en primera iteración



Mobile-first design (80% usuarios móvil)



Accesibilidad: Contraste adecuado, textos legibles, navegación por teclado



Performance: Lighthouse score >90



Sin backend real si complica: Usar localStorage + JSON para MVP



Foco en UX fluida: Mínimo 2 clicks para completar pedido
